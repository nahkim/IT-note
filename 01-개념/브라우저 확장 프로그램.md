# 브라우저 확장 프로그램 (Browser Extension)

## 한 줄 정의
HTML·CSS·JS로 만들어 **브라우저 자체의 기능과 웹 페이지를 바꾸는 작은 프로그램** — 광고 차단기, 비밀번호 관리자, 개발 도구 등.

## 자세히

### 구성 요소
- **`manifest.json`** — 이름·버전·**권한(permissions)**·진입점을 선언하는 명세서. 확장의 신분증.
- **콘텐츠 스크립트(content script)** — 실제 웹 페이지의 [[DOM]]에 주입되어 페이지를 읽고 고친다. 단, 페이지의 JS 변수와는 **격리된 세계(isolated world)** 에서 실행.
- **백그라운드(서비스 워커)** — 이벤트를 받아 처리하는 두뇌. 탭·저장소·네트워크 API 담당.
- **팝업 / 옵션 페이지 / 사이드 패널** — 사용자가 보는 UI.
- **권한 모델** — `host_permissions`(어떤 사이트에 접근할지), `storage`, `tabs` 등. 설치할 때 뜨는 "이 확장이 **모든 웹사이트의 데이터를 읽고 변경**할 수 있습니다"가 이것.

### Manifest V3 (MV3) — 지금의 표준
- **지속 백그라운드 페이지 → 이벤트 기반 서비스 워커**로 대체. 필요할 때 깨어나고 유휴 시 **종료**된다 → **전역 변수에 상태를 두면 사라진다.** 상태는 `chrome.storage`에 저장해야 한다.
- **원격 코드 실행 금지** — 외부에서 스크립트를 받아 실행할 수 없다(패키지에 든 코드만).
- **`webRequest` 차단 방식 → `declarativeNetRequest`** — 확장이 트래픽을 들여다보며 막는 대신, **규칙을 선언하면 브라우저가 대신 적용**한다. 프라이버시·성능은 좋아졌지만, 광고 차단기의 동적 필터링 능력이 제한돼 큰 논쟁이 됐다.
- **전환 일정**: MV2는 이미 사용 중지 수순 — Chrome 138(2025년 7월) 이후 안정 채널에서 MV2 확장이 동작하지 않고, 2026년에 개발자 플래그(7/28)와 웹 스토어 정리(8/31)로 마무리된다. 신규 개발은 **MV3만**.
- Firefox는 MV3를 지원하되 `webRequest` 차단을 **유지**하는 등 세부가 다르다 → 크로스 브라우저 확장은 분기 처리가 필요.

### 보안 관점 — 확장은 강력한 만큼 위험하다
- 콘텐츠 스크립트는 사실상 **모든 페이지에 코드를 주입**할 수 있다. 즉 **[[XSS]]를 합법적으로 하는 권한**을 가진 셈.
- 실제 사고 유형: 인기 확장이 **인수·매각된 뒤 악성 업데이트**를 배포, 개발자 계정 탈취(피싱)로 악성 버전 푸시, 세션 쿠키·입력값 탈취.
- 대응: 설치 수·개발자·리뷰 확인, **요구 권한이 기능에 비해 과한지** 보기, 안 쓰는 확장 제거, 업무 환경에선 **정책으로 허용 목록** 운영. 확장도 별도 프로세스·권한 경계를 갖지만([[브라우저 프로세스와 사이트 격리]]) **사용자가 준 권한 안에서는 자유**다.

## 왜 중요한가
- 브라우저를 **플랫폼**으로 만드는 요소 — 웹 기술만으로 브라우저 기능을 확장할 수 있다 ([[애플리케이션 형태]]).
- 동시에 **기업 보안의 사각지대**: 사용자가 자유롭게 설치하는 코드가 사내 웹 시스템의 모든 화면을 읽을 수 있다.
