# Self-XSS (셀프 크로스 사이트 스크립팅)

## 한 줄 정의
사이트의 취약점이 아니라 **사용자를 속여서, 사용자가 직접 자기 브라우저 콘솔에 악성 코드를 붙여넣고 실행하게 만드는** 사회공학 공격.

## 자세히

### 어떻게 당하나
공격자는 취약점을 뚫지 않는다. **사용자의 손을 빌린다.**
1. "숨겨진 기능 해제", "게임 아이템 무료", "친구 계정 해킹하는 법", "보안 점검 코드" 같은 미끼로 코드 한 덩어리를 준다.
2. 피해자가 `F12` → **콘솔(Console)** 에 붙여넣고 Enter.
3. 그 코드는 **피해자의 로그인 세션 안에서** 실행된다 → 쿠키·토큰 탈취, 본인 명의 글 작성·전송, 계정 탈취, 친구에게 같은 미끼 전파.

> 💡 핵심: 콘솔에 붙여넣은 코드는 **그 사이트의 정식 스크립트와 완전히 동일한 권한**을 갖는다. [[동일 출처 정책]]도 [[CORS]]도 막지 않는다 — 이미 "같은 출처 안"이기 때문. `HttpOnly` 쿠키를 직접 읽지는 못해도, **브라우저가 알아서 쿠키를 실어 보내는** API 요청은 얼마든지 만들 수 있다.

### 일반 [[XSS]]와 뭐가 다른가
| | 일반 XSS | Self-XSS |
|---|---|---|
| 원인 | 사이트의 **코드 취약점** | 사용자의 **행동**(속아서 붙여넣기) |
| 개발자가 고칠 수 있나 | 예 (인코딩·[[CSP]]) | 코드로는 못 고침 → **경고·교육**으로 대응 |
| 버그바운티 | 인정 | 보통 **취약점으로 인정 안 함** (단, 다른 버그와 엮어 무기화되면 인정되기도) |

### 브라우저의 방어 — "allow pasting"
질문에서 본 그 경고문이 이것이다.

> "Warning: Don't paste code into the DevTools Console that you don't understand… Please type **allow pasting** below and press Enter to allow pasting."

- **Chrome DevTools**가 Chrome 120부터 기본 활성화한 **self-XSS 보호(붙여넣기 방지)**. Console과 Sources 패널에서 붙여넣기를 막고, 사용자가 직접 `allow pasting`을 **타이핑**해야 풀린다.
- **왜 하필 타이핑인가**: 미끼 글에 있는 "그냥 확인 누르세요"를 못 하게, **손으로 문장을 입력하는 마찰(friction)** 을 넣은 것. 코드를 붙여넣는 순간이 곧 위험한 순간이므로, 그 자리에서 "이게 뭔지 아느냐"를 묻는다.
- **판별 기준(휴리스틱)**: 프로필의 **콘솔 히스토리가 5건 이상**이면 "개발자"로 보고 경고를 아예 안 띄운다. 개발자에겐 방해가 안 되고, 비개발자만 잡는 설계. 한 번 허용하면 그 프로필에선 다시 묻지 않는다.
- **자동화 예외**: 테스트 자동화용으로는 **Chrome for Testing**(기본 비활성) 또는 `--unsafely-disable-devtools-self-xss-warnings` 플래그.
- Firefox도 같은 방식(`allow pasting` 입력)의 경고를 쓴다. Facebook은 그 전부터 콘솔을 열면 **거대한 빨간 경고문**을 찍는 방식으로 대응해왔다.

### 실무에서 기억할 것
- **모르는 코드는 콘솔에 절대 붙여넣지 않는다.** "고객센터 직원"이 시켜도 마찬가지 — 정상적인 서비스는 사용자에게 콘솔 코드를 요구하지 않는다.
- 개발자여도 위험하다. 스택오버플로/블로그/AI 답변에서 복사한 스니펫도 **로그인 상태의 실서비스 탭**에서 실행하면 같은 결과가 난다. → 시크릿 창·로컬 환경에서 확인.
- 서비스 운영자라면: 콘솔 경고 문구 출력, [[쿠키 세션 JWT|세션 쿠키]]에 `HttpOnly`·`SameSite`, 중요 작업에 재인증, 이상 행위 탐지가 실질적 완화책.

## 왜 중요한가
- **기술적 방어의 바깥**에 있는 공격이다. 서버·프레임워크를 아무리 단단히 해도 사용자가 스스로 실행하면 끝 → "사람이 마지막 방어선"의 대표 사례.
- Chrome이 브라우저 레벨에 마찰을 넣었다는 것 자체가, **사회공학이 실제로 대규모 피해를 냈다**는 증거(Facebook·Steam 계정 탈취 캠페인 등).
