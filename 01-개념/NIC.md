# NIC (네트워크 인터페이스 카드)

## 한 줄 정의
컴퓨터를 **네트워크에 물리적으로 연결**해주는 하드웨어. 내부의 디지털 데이터를 케이블·빛·전파로 실어 보내고 받으며, 장치를 구별하는 **고유 주소(MAC)**를 갖는다. 흔히 **랜카드 / 네트워크 어댑터**라고 부른다. (Network Interface **Card**, 요즘은 **Controller**)

## 자세히

### 하는 일
- **신호 변환** — 컴퓨터 내부의 디지털 데이터 ↔ 전송 매체(구리선의 전기신호 · 광섬유의 빛 · 무선의 전파)로 바꿔 실어 보냄.
- **프레임 캡슐화** — 데이터를 **이더넷 프레임**으로 포장하고, 받은 프레임을 해체.
- **주소 지정·매체 접근 제어(MAC)** — MAC 주소로 같은 네트워크 안의 목적지를 구별하고, "언제 신호를 보낼지"를 규칙에 맞춰 관리(충돌 회피 등).

### OSI 계층 위치 — L1 + L2에 걸침
- **물리 계층(L1)**: 실제 신호를 매체에 싣고 받는 부분.
- **데이터링크 계층(L2)**: MAC 주소 부여·프레임 처리.
- → NIC은 이 **두 계층에 걸친 장치**다. → [[OSI 7계층]]

### MAC 주소
- NIC마다 새겨진 **48비트 고유 식별자**(예: `00:1A:2B:3C:4D:5E`). 앞 24비트는 **제조사 코드(OUI)**, 뒤 24비트는 일련번호.
- **IP가 바뀔 수 있는 "논리 주소"**라면, **MAC은 하드웨어에 붙박인 "물리 주소"**. 같은 네트워크에선 MAC으로, 네트워크를 넘어가면 IP로 찾아간다. → [[TCP-IP]]

### 형태·종류
- **유선(이더넷)** vs **무선(Wi-Fi/WLAN 카드, 안테나 포함)**.
- 요즘 PC·노트북은 **메인보드에 내장(온보드 LAN, LOM)**. 별도 증설은 **PCIe 확장 카드**.
- 서버용은 속도가 관건 — **1G / 10G / 25G / 40G / 100G / 200G / 400G** 이더넷.
- **가상 NIC(vNIC)** — VM·컨테이너가 쓰는 소프트웨어 네트워크 카드. → [[쿠버네티스]]

### 오프로딩 — CPU 부담 덜기
NIC이 네트워크 잡일을 대신 처리해 **CPU 자원을 앱 연산에 돌려주는** 기능들:
- **체크섬 오프로드 · TCP 오프로드(TOE) · 세그멘테이션** — 패킷 처리 연산을 NIC이 대신.
- **RSS** — 수신 트래픽을 여러 CPU 코어로 분산.
- **SR-IOV** — 하나의 물리 NIC을 가상머신들이 **직접 나눠** 쓰게 함.

### SmartNIC / DPU — NIC의 진화
- **SmartNIC**: 프로그래머블 코어를 얹어 **패킷 필터링·암호화·가상 스위칭**까지 NIC이 직접 수행. host CPU와 독립적으로 패킷을 처리하는 **코프로세서**처럼 동작.
- **DPU(Data Processing Unit)**: 자체 **CPU·메모리·OS**를 가진 "네트워크 전용 소형 컴퓨터". 네트워크·보안·스토리지 처리를 host CPU에서 **완전히 떼어내** 데이터센터의 CPU를 순수 애플리케이션 연산에만 집중시킨다. 관리 도메인도 host와 분리(독립 OS·자격증명·원격접속).

## 왜 중요한가
- 네트워크 통신의 **물리적 출발점** — NIC이 없으면 IP·TCP·HTTP 등 어떤 상위 프로토콜도 밖으로 못 나간다.
- **대역폭·오프로딩 성능이 서버 처리량과 직결** — 고성능 서버·데이터센터에선 NIC 선택이 병목을 좌우한다.
- **MAC 주소**는 스위칭·DHCP·네트워크 접근제어(포트 보안)의 기준점이 된다.

## 관련 개념
- [[OSI 7계층]] — NIC은 L1(물리)·L2(데이터링크)에 걸친 장치
- [[TCP-IP]] — NIC의 MAC(물리주소) 위에서 IP(논리주소)가 돈다. TCP 오프로드(TOE)도 NIC 기능
- [[GPU vs CPU]] — DPU는 "네트워크판 오프로드 가속기". 특정 일을 전용 하드웨어로 떼어내는 발상이 같다
- [[쿠버네티스]] — 가상 NIC(vNIC)·SR-IOV로 컨테이너 네트워킹을 구성
