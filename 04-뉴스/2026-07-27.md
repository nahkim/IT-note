> ⏳ **회고 정리(retrospective)** — 이 날짜는 자동 수집이 누락되어, **2026-07-30에 사후 검색으로 작성**했습니다. 발표 당시 실시간 수집분이 아니라 **지금 시점 검색 기준**이라 일부 후속 정정(예: 패치 후 CVSS 조정)이 반영됐을 수 있습니다.

## 🤖 AI / LLM (핵심 — NVIDIA, Ilya Sutskever의 SSI에 대규모 투자·컴퓨트 공급)

- **NVIDIA ↔ Safe Superintelligence(SSI) 장기 전략적 파트너십**: NVIDIA가 Ilya Sutskever(전 OpenAI 공동창업자)가 이끄는 **SSI에 지분 투자**(블룸버그 보도 기준 **$50억 규모**)하고, 차세대 **Vera Rubin 플랫폼**을 공급하기로 했다. SSI는 이를 통해 **컴퓨트를 한 자릿수 배수(order of magnitude) 확대**할 수 있게 된다. "제품도 매출도 없는" 순수 연구 랩에 하이퍼스케일러급 자본·가속기가 몰리는 흐름으로, 프런티어 경쟁의 병목이 **자본+GPU 확보**임을 다시 보여줬다. (→ [[GPU vs CPU]] · [[nvidia-smi]] · [[온프레미스]] · [[LLM]])
- **Cognizant ↔ Anthropic 파트너십 확대 — Claude를 산업 플랫폼에 내장**: Cognizant가 **Claude Partner Network의 최상위(Global Premier Partner)** 로 올라서며, 자사 비즈니스·엔지니어링 플랫폼 전반에 **Claude를 임베드**한다. **3만 명 이상**이 Claude 교육을 이수했고(Frontier Certified 인력 모델), 제조·생명과학·보험 등 규제 산업에서 **계약 검토 40% 단축·보험 언더라이터 주당 8시간 절감** 같은 실 production 성과를 제시했다. 'AI 약속과 실제 성과의 간극'을 산업 규모로 좁히려는 대형 SI의 베팅. (→ [[AI 에이전트]] · [[RAG]] · [[프롬프트 엔지니어링]])
- **7월 프런티어 릴리즈 러시의 여진**: 직전 주 [[2026-07-24]]의 Claude Opus 5를 비롯해 7월 한 달간 OpenAI(GPT-5.6 계열)·Anthropic·Google DeepMind·xAI(Grok 4.5) 등에서 릴리즈가 쏟아진 여파가 이어졌다. 에이전트·오픈소스·코딩 모델이 특히 활발. (→ [[LLM]] · [[Transformer]] · [[AI 에이전트]])

## ☁️ 클라우드 / 인프라 (핵심 — 추론 수요 중심 데이터센터 확장, GPU 클라우드 실적 시즌)

- **NVIDIA Vera Rubin, 대형 랩 전용 공급 사례로 — 차세대 가속기 배분 경쟁**: SSI 건은 투자이자 **차세대 가속기(Vera Rubin) 우선 배분** 계약이기도 하다. 프런티어 랩들이 자본과 함께 **차세대 GPU 물량 선점**에 나서는 구도가 뚜렷해졌다. (→ [[온프레미스]] · [[수평 확장]] · [[nvidia-smi]])
- **GPU 클라우드 실적 시즌 개막 — CoreWeave Q2 콜 일정 공지·Applied Digital FY26 결산**: 7/27 CoreWeave가 **2분기 실적 발표 일정**을 공지했고, Applied Digital은 **회계 4분기·FY2026 실적**을 냈다. AI 인프라(GPU 코로케이션·호스팅) 사업자들의 수요·capex가 시장 관심사로 부상. (→ [[수평 확장]] · [[로드 밸런서]] · [[멀티테넌시]])
- **데이터센터 수요, '훈련'에서 '추론'으로 무게 이동**: 7월 업계 동향 정리에서 공통적으로, 배포의 상당 부분이 **프런티어 모델 훈련이 아니라 추론(inference) 워크로드**로 옮겨가면서 **고가용성·지리적 분산·낮은 지연** 요구가 커진다는 진단이 나왔다. 이는 서빙 계층 설계와 직결. (→ [[캐시]] · [[CDN]] · [[AI 모델 서빙 프레임워크]])

## 🔐 개발 / 보안 (핵심 — Gitea 미인증 RCE·vBulletin/Fortinet 악용)

- **Gitea `CVE-2026-60004`(RCE, CVSS 9.8) — 1.27.1에서 수정(7/27 배포)**: `diffpatch` API를 통해 **공격자가 제어한 패치 내용을 살아있는 Git 훅으로 심어** Gitea 서비스 계정 권한으로 셸 명령을 실행할 수 있다. API 호출에 저장소 쓰기 권한이 필요하지만, **Gitea가 기본적으로 회원가입을 허용**해 외부인이 계정·저장소를 만들어 **사실상 미인증에 준하게 악용** 가능. 백포트가 7/26 머지되고 **1.27.1이 7/27 배포**, 보안 권고와 **PoC 코드**는 7/28 공개(당시 실악용 정황은 명시 안 됨). Gitea Cloud는 자동 업그레이드. (→ [[Git]] · [[형상관리]] · [[OWASP Top 10]] · [[인증과 인가]])
- **vBulletin 원격 코드 실행 — 공개 익스플로잇(7/27)**: 미인증 요청이 vBulletin 내부의 PHP `eval()`에 도달해 **패치 안 된 포럼 서버에서 코드 실행**이 가능함을 보이는 익스플로잇 상세가 7/27 공개됐다. 널리 쓰이는 포럼 소프트웨어라 노출 자산이 표적이 되기 쉽다. (→ [[OWASP Top 10]] · [[웹사이트 보안]])
- **Fortinet FortiOS 민감정보 노출 결함, CISA KEV 등재(7/27)**: FortiOS 7.6.0~7.6.1의 **민감정보 노출(비인가 행위자에 정보 노출)** 취약점이 7/27 **CISA 알려진 악용 취약점(KEV)** 목록에 추가됐다. [[2026-07-30]]의 FortiSandbox 명령주입 KEV(7/16)에 이어 **온프레미스 보안 어플라이언스** 표적화가 계속되는 맥락. (→ [[인증과 인가]] · [[온프레미스]] · [[리버스 프록시]])
