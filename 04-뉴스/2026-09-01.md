# 📰 IT 신기술 뉴스 — 2026-09-01

> [[2026-08-31]]에서 이어짐. 9월 첫 영업일(KST 화요일). 축은 셋이다 — ① AI에선 **분쟁의 계절** — OpenAI가 **SpaceX에 인수된 Cursor의 모델 접근을 끊고**(머스크와의 갈등 격화), **음악 퍼블리셔 35곳이 Anthropic을 저작권 침해로 제소**, 한편 중국 **Z.ai가 오픈웨이트 `GLM-5.3-Flash`를 MIT로 공개**했다. ② 인프라는 **전력=병목**이 다시 주제 — **Anthropic $45B 컴퓨트 계약**과 **Meta의 'Meta Compute' 신설**이 기가와트 단위 경쟁을 못 박았다. ③ 보안에선 **CISA KEV에 6건 추가(NetScaler 제로데이)**, **맨체스터 공항 침해의 범인(FulcrumSec)이 수법을 공개**했고, **Windows IKE 무인증 RCE**가 야생에서 악용됐다.

## 🤖 AI / LLM

- **OpenAI, `Cursor`의 모델 접근 차단 통보(8/28) — SpaceX 인수가 방아쇠, 머스크와 갈등 격화**: OpenAI는 **SpaceX가 $60B에 인수(6월 발표·8월 완료)한 코딩 툴 Cursor**에 대해 계약 종료를 통보했고, **모델 접근은 11/12에 끊긴다**. 근거는 "머스크 계열사(X 등)의 계약 위반 이력상 TOS 준수를 신뢰할 수 없다"는 것. Cursor는 **OpenAI 모델이 전체 트래픽의 ~5%**라 타격은 제한적이라고 반박했다. 앤트로픽·구글 등 대체 모델로의 이동이 불가피한 구도. (→ [[AI 에이전트]] · [[LLM]] · [[클라이언트 앱]])
- **음악 퍼블리셔 35곳(소니뮤직 퍼블리싱·워너 채플 등), Anthropic 제소(8/28) — CEO 아모데이 개인까지 피고**: 캘리포니아 북부지법 제소로, **가사 저작물 수만 곡을 해적·스크래핑으로 학습에 썼고 저작권 관리정보(CMI)—곡명·작곡가·퍼블리셔·저작권 표시—를 제거**했다고 주장한다. 청구는 **고의 침해작당 최대 $150,000, CMI 제거당 최대 $25,000**로 이론상 수십억 달러 규모. 유니버설/콘코드/ABKCO의 **2026년 1월 2만+곡·$3B+ 소송**에 더해 **3대 퍼블리셔가 모두 Anthropic과 소송** 중인 국면이 됐다. (→ [[LLM]] · [[파인튜닝]])
- **Z.ai, `GLM-5.3-Flash` 오픈웨이트 공개(8/26) — 320B/활성 18B MoE, 100만+ 토큰, MIT 라이선스**: 하이브리드(선형+희소) 어텐션의 **총 320B·토큰당 활성 18B MoE**로, **컨텍스트 1,048,576토큰**과 **네이티브 멀티모달(텍스트·이미지·비디오·파일)**을 갖췄다. **가중치는 허깅페이스에 MIT로 공개**되고, Z.ai는 GLM-5.2 대비 성능↑·**가격 약 1/10**을 내세운다(코드명 'Ox Alpha'). 코딩·에이전트·롱컨텍스트용 저비용 대안 포지셔닝. (→ [[LLM]] · [[토큰]] · [[로컬 LLM과 셀프호스팅]])

## ☁️ 클라우드 / 인프라

- **Anthropic, Nscale와 $45B·6년 컴퓨트 계약(8/26) — 460MW·Vera Rubin, 병목은 '전력'**: 웨스트버지니아 **Monarch 캠퍼스에서 약 460MW** 규모를 확보한다. **그리드가 아니라 캐터필러 가스 발전기로 현장 자가발전**하고, 엔비디아 **Vera Rubin** 칩으로 **2027년 말** 서비스 투입 예정. 부지는 **최대 8GW** 잠재력이며, **MS도 같은 캠퍼스에서 최대 1.35GW**를 잡았다. 칩보다 '언제 전력을 붙이느냐'가 경쟁 축이 됐음을 보여준다. (→ [[온프레미스]] · [[수평 확장]] · [[GPU vs CPU]])
- **Meta, 'Meta Compute' 조직 신설 — 이번 세대 수십 GW → 장기 수백 GW**: 인프라 총괄 산토시 자나르단과 대니얼 그로스가 공동으로 이끄는 컴퓨트 전담 조직을 세웠다. **Hyperion(루이지애나, 2,250에이커, 약 $10B, 최대 5GW)**·**Prometheus(오하이오, 2026년 가동)** 등 초대형 캠퍼스를 앞세워, "이번 세대 수십 GW·장기적으로 수백 GW"를 짓겠다는 계획이다. 자나르단은 아키텍처·칩·데이터센터를, 그로스는 용량 계획·전략 파트너십·장기 경제 모델링을 맡는다. (→ [[수평 확장]] · [[온프레미스]] · [[GPU vs CPU]])
- **Cisco, 엔비디아 'Secure AI Factory'를 랙스케일로 확장(8/25) — Supermicro 합류**: 시스코가 **엔비디아·Supermicro와 손잡고** 액랭·공랭 고밀도 GPU 랙스케일 시스템을 풀스택 보안 AI 인프라에 편입한다. 네오클라우드·소버린 클라우드를 겨냥한 **NCP(NVIDIA Cloud Partner) 준수 아키텍처**로, **작업 상태를 컴퓨트·NIC·광통신·네트워크 지표와 상관 분석**하는 엔드투엔드 관측성을 제공한다. Supermicro 옵션은 **2026년 10월**부터 판매. (→ [[NIC]] · [[쿠버네티스]] · [[GPU vs CPU]])

## 🔐 개발 / 보안

- **CISA, KEV에 6건 추가(8/26) — Citrix NetScaler 제로데이 `CVE-2026-8452`(CVSS 8.8) 실제 악용**: NetScaler ADC/Gateway의 **메모리 버퍼 침해** 결함으로, **게이트웨이/AAA 가상서버 구성에서 인증 전 도달·코드 실행·DoS**가 가능하다. 공격자는 **`x.php`·`z.php` 웹셸을 심고** `id`·`echo` 같은 정찰 명령을 돌렸으며, **12일간 12개 IP에서 36회 시도**가 관측됐다. 함께 추가된 **SQL Server `CVE-2019-1068`과 NetScaler는 8/29**, 리눅스 커널·Red Hat ABRT/libuser·Ajax.NET 등 **나머지는 9/9**가 연방기관 패치기한. (→ [[인증과 인가]] · [[리버스 프록시]] · [[OWASP Top 10]])
- **맨체스터 공항그룹(MAG) 침해 후속 — 협박그룹 FulcrumSec, "86GB 탈취" 주장·노출된 API 키가 원인(8/30~31)**: [[2026-08-31]]에서 다룬 **870만 명 침해**의 범인·수법이 드러났다. FulcrumSec는 **클라이언트 측 JavaScript에 노출된 Iterable API 자격증명**으로 접근해 **약 86GB(고객 익스포트 21.5GB 포함)**와 **2026년 잔여 여행 관련 약 20만 건**을 빼냈다고 주장한다. 브라우저 개발자 도구로도 보일 수 있던 키가 화근으로, 샘플엔 예약참조·주차일·IP·기기정보·UK 우편번호가 있었고 **카드·계좌 정보는 없었다**. (→ [[개발자 도구]] · [[REST API]] · [[환경 변수]] · [[OWASP Top 10]])
- **Windows IKE/IPsec `CVE-2026-33824`(CVSS 9.8) 무인증 RCE 야생 악용 — 4월 패치, 8/18 KEV 등재**: Microsoft **IKE 서비스 확장의 double-free** 결함으로, **UDP 500/4500 포트에 조작된 패킷**만으로 **인증 없이 원격 코드 실행**이 가능하다(전 지원 Windows 10·11·Server 해당). 4월에 조용히 패치됐다가 넉 달 뒤 실제 악용이 확인돼 **CISA가 8/18 KEV에 등재(기한 8/21)**했고, Unit 42는 **중국어권 위협 행위자의 'AI 자율 해킹' 캠페인**과 연계된 악용을 관측했다. IPsec VPN을 외부에 여는 조직은 즉시 패치가 필요. (→ [[암호화와 해싱]] · [[TCP-IP]] · [[OWASP Top 10]])
