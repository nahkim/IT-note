# 📰 IT 신기술 뉴스 — 2026-10-22

## 🔐 개발 / 보안

- **PHP 코어 `PHP2Shell`(`CVE-2026-109618`·`CVE-2026-109619`, CVSS 9.2) 무인증 RCE — 사전유출→실악용으로 10/21 긴급 패치 — 웹 요청을 처리하는 모든 PHP 설치(PHP-FPM·Apache mod_php·php-cgi·FrankenPHP·LiteSpeed; mod_php가 가장 위험)에 영향, `CVE-2026-109618`은 OOM(메모리 부족) 처리 중 내부 요청 데이터가 '부분 초기화' 상태에서 유효로 오인되는 메모리 손상, `CVE-2026-109619`는 요청 소유 상태가 해제 후에도 남아 다음 요청이 소비하는 'heap use-after-free'로 메모리 노출·RCE 가능, 조정 공개 전 상세가 유출돼 가속 릴리스, 10/21 `PHP 8.5.12·8.4.27·8.3.36·8.2.35` 패치(7.4/8.0/8.1은 소스 백포트), watchTowr 허니팟·Cloudflare 트래픽에서 실악용 관측**: **단 한 번의 '인증 없는 요청'으로 애플리케이션 코드 실행 전에 서버를 장악할 수 있어, 웹을 떠받치는 런타임 자체가 초기 침투구가 됐다**(Help Net Security·BleepingComputer·SecurityWeek·Qualys·Tenable 확인). 임시 완화(`CVE-2026-109619`)는 `session.upload_progress.enabled=0` 후 전 워커 재시작이지만 **근본 해결은 패치 적용뿐**이다. (→ [[가비지 컬렉션과 메모리]] · [[프로세스와 스레드]] · [[OWASP Top 10]] · [[WAF]] · [[셀프호스팅]])
- **GitLab `CVE-2026-97229`(CVSS 10.0) — CI/CD 정규식 컴파일러 정수 오버플로로 무인증 RCE — CI/CD 정규식(Regular Expression) 컴파일러의 정수 오버플로(불충분한 정규식 검증)로, 특정 조건에서 인증·사용자 상호작용 없이 공격자가 조작한 표현식으로 서버에서 임의 코드 실행 가능, GitLab CE/EE `19.2.8·19.3.5·19.4.2`(10/12 배포)에서 수정, Rapid7은 'CVSS는 무인증(10.0)이나 실제 악용에는 전제 조건이 있다'는 단서를 지적**: **소스 호스팅·파이프라인의 중심인 GitLab에서 '정규식 처리'라는 흔한 기능이 최대 심각도 결함이 됐다**(The Hacker News·Help Net Security·SOC Prime 확인). 현재까지 실악용 징후·CISA KEV 등재는 없으나(10/22 기준), **인터넷 노출 셀프호스트 인스턴스는 즉시 패치**가 권고된다. (→ [[정규표현식]] · [[CI-CD]] · [[셀프호스티드 러너]] · [[OWASP Top 10]] · [[셀프호스팅]])
- **CISA, 10/20 `Plex Media Server` 4종 등 6개 CVE를 실악용 목록(KEV)에 추가 — 셀프호스트 미디어 서버가 공격면 — Plex Media Server의 SSRF 2종(`CVE-2026-96652`·`CVE-2026-96655`), 인코딩된 URI 스킴 부적절 처리(`CVE-2026-96654`), 파일 경로 외부 제어(`CVE-2026-96656`)와 함께 `EG Secure SiteGuard`의 OS 명령 주입(`CVE-2026-106931`)·[[2026-10-21]]에서 다룬 Siemens Software Center(`CVE-2026-110936`)가 실악용 증거로 등재**: **[[2026-10-21]]의 Nextcloud Collabora에 이어, 개인·소규모가 흔히 올려두는 셀프호스트 서비스(Plex)가 반복적으로 공격 대상이 되고 있다**(CISA 공식·cvefeed 확인). SSRF는 내부망 요청 위조로 이어질 수 있어 **노출 최소화·즉시 패치**가 핵심이다. (→ [[셀프호스팅]] · [[리버스 프록시]] · [[인증과 인가]] · [[WAF]] · [[OWASP Top 10]])
