# 📰 IT 신기술 뉴스 — 2026-08-28

> [[2026-08-27]]에서 이어짐. 어제가 'Nvidia 실적이 못 박은 AI 수요 변곡점'이었다면, 오늘의 축은 **에이전트가 SaaS 안으로 들어가는 날**이다 — Salesforce와 Anthropic이 CRM 전체를 Claude 안에 넣은 **Claudeforce**를 발표했고, **Claude in Chrome이 정식 출시(GA)**되며 브라우저를 대신 조작하는 '일하는 AI'가 유료 전 플랜으로 열렸다. 클라우드에선 **Synergy Q2 시장 $143B(+43% YoY)**로 8년 만의 최고 성장률이 찍혔고, 보안에선 **Citrix NetScaler `CVE-2026-8452`가 실제 악용으로 CISA KEV에 등재**되며 '패치했다고 끝이 아니다'를 다시 증명했다.

## 🤖 AI / LLM

- **Salesforce × Anthropic, `Claudeforce` 발표(8/26) — CRM 전체가 Claude 안으로**: 두 회사가 전략적 파트너십을 확대해, **`Salesforce in Claude`** 플러그인을 첫 결과물로 내놨다. **미리 만들어진 37개 영업 스킬**(미팅 준비·딜 건전성 점검·파이프라인 리뷰 등)로, 판매자·에이전트가 **Salesforce 앱을 열지 않고도** Claude에서 실시간 매출 컨텍스트를 추론하고 파이프라인을 갱신하며 거버넌스가 걸린 액션을 실행한다. **파일럿 고객에 오늘부터** 제공, **9월 오픈 베타** 예정이며 앞으로 Claude·Salesforce·Slack에 걸쳐 통합을 넓힌다. 마크 베니오프가 'SaaS 종말론(SaaSpocalypse)' 우려에 답하는 성격의 발표라는 해석도 붙었다. (→ [[AI 에이전트]] · [[REST API]] · [[멀티테넌시]] · [[인증과 인가]])
- **Anthropic, `Claude in Chrome` 정식 출시(GA, 8/26) — 승인 없이 웹을 대신 조작하는 브라우저 에이전트**: 유료 전 플랜에서 쓸 수 있게 되었고, **매 단계 일일이 승인하지 않아도** 페이지를 읽고 링크를 클릭하고 폼을 채우는 작업을 **기존 로그인 세션 그대로** 자율 수행한다. 안전장치로 **모든 액션을 사전 검증하는 안전 분류기(safety classifier)**가 붙어, 요청과 일치하고 위험하지 않은지 확인한 뒤에 실행한다. 나란히 **Claude Cowork에는 확장 프로그램 없이 쓰는 내장 브라우저**도 추가돼(8/27 보도), Chrome 확장에 의존하던 웹 접근을 자체 브라우저로 대체하기 시작했다. (→ [[AI 에이전트]] · [[브라우저 확장 프로그램]] · [[인증과 인가]])
- **Z.ai `GLM-5.3` — '재학습 없이' 코딩·사이버 특화, 오픈웨이트 공개는 이번 주 예정(미확정)**: 8/14 출시된 GLM-5.3은 **GLM-5.2와 같은 743B 파라미터 베이스를 그대로 두고 포스트트레이닝만 확대**해, Terminal-Bench 3.0을 4.6%→28.3%로 끌어올렸다. 사이버보안 벤치 **CyberGym 84.5%**로 경쟁 모델을 앞선다고 밝혔고, 컨텍스트 100만 토큰·출력 12.8만 토큰. Z.ai는 안전성 검증 후 **출시 2주 뒤 오픈웨이트 공개**를 예고했는데(대략 오늘 무렵), 8/17 시점까지 실제 가중치는 게시되지 않아 **공개 여부·시점은 미확정**이다. (→ [[LLM]] · [[토큰]] · [[파인튜닝]] · [[CUDA]])

## ☁️ 클라우드 / 인프라

- **Synergy Research, Q2 2026 클라우드 인프라 시장 $143B — 8년 만의 최고 성장률 +43% YoY**: 전년 동기比 **$43B 넘게 늘어** 분기 $143B에 도달, **11분기 연속 성장**이자 최근 8년 중 가장 높은 성장률이다. 특히 **생성형 AI 전용 클라우드 서비스가 +165% YoY**로 폭증했지만, AI는 그 자체 매출을 넘어 여타 클라우드 서비스 전반의 기능·성장까지 끌어올리는 촉매로 작동 중이다. (→ [[수평 확장]] · [[서버리스]] · [[온프레미스]])
- **하이퍼스케일러 자본지출, 2026년 ~$750B 육박 — 건설 중 DC 용량 23GW 돌파**: [[2026-08-27]]에서 정리한 'GPU 매출로 환류되는 인프라 투자 사이클'이 지출 계획으로도 이어진다. **Amazon $200B**·**Google $195~205B**(직전 가이던스 $180~190B에서 상향) 등 상위 하이퍼스케일러의 capex 상향이 잇따르며, 건설 중인 데이터센터 IT 용량은 **23기가와트**를 넘어섰다. 병목은 여전히 칩이 아니라 **전력·부지**라는 구도가 유지된다. (→ [[온프레미스]] · [[수평 확장]] · [[GPU vs CPU]])
- **투자의 착지점 — OpenAI·Oracle 'Stargate' 4.5GW·~$300B, 텍사스 애빌린 8개 동 연말 완공 목표**: 위의 capex가 실제로 꽂히는 대표 사례. OpenAI와 Oracle이 미국 내 **4.5GW 규모 Stargate 데이터센터**를 약 $300B 투자로 구축 중이며, 애빌린 부지의 **마지막 건물은 2026년 말 완공** 예정이다. '연산=국가 규모 인프라'라는 서사가 물리적 건물로 굳어지는 국면. (→ [[온프레미스]] · [[수평 확장]] · [[GPU vs CPU]])

## 🔐 개발 / 보안

- **CISA, Citrix NetScaler `CVE-2026-8452` KEV 등재(8/26) — 실제 악용 확인, 연방기관 기한 8/29**: NetScaler ADC/Gateway의 **SAML 인증 메시지 처리 중 메모리 손상** 취약점으로, 서명 검증 과정에서 조작된 SAML 메시지가 메모리를 오염시켜 **미인증 원격 코드 실행(RCE)**로 이어진다(watchTowr가 PoC로 시연). 실제로 공격자들이 **`x.php`·`z.php` 웹셸**을 심고 `id`·`echo`로 정찰하는 정황이 관측됐다. **AAA 가상서버 또는 Gateway VPN**으로 구성된 장비만 해당되며, Citrix는 이미 **6/30 패치**를 냈으나 미적용 인스턴스가 노출됐다. CVSS는 **Citrix v4.0 8.8 / NVD v3.1 9.8**. (→ [[리버스 프록시]] · [[인증과 인가]] · [[OWASP Top 10]] · [[HTTP 헤더]])
- **같은 날 KEV에 총 6건 추가 — MS SQL Server RCE `CVE-2019-1068` 등 오래된 결함이 다시 '실제 악용'으로**: NetScaler와 함께 **MS SQL Server RCE(`CVE-2019-1068`, 기한 8/29)**, Linux 커널 OOB 쓰기(`CVE-2022-0995`), Red Hat ABRT/libuser 권한상승(`CVE-2015-5287`·`CVE-2015-3246`), Ajax.NET 역직렬화(`CVE-2021-23758`)가 한꺼번에 올랐다. 나머지 4건 기한은 **9/9**. 수년 전 패치가 나온 취약점들이 여전히 현역 공격 표면임을 상기시킨다. (→ [[관계형 데이터베이스와 SQL]] · [[인증과 인가]] · [[OWASP Top 10]])
- **배경 위협 — Cisco Talos, 중국계 사이버범죄 그룹 `UAT-10147`이 전 세계 웹서버 겨냥**: 이번 KEV 확대는 Talos가 공개한 **UAT-10147** 보고와 맞물린다. 이 그룹은 교육·미디어·기술·게임 분야에 걸쳐 **Windows·Linux 웹서버를 전 세계적으로 표적**으로 삼는다. NetScaler 같은 '인터넷에 노출된 경계 장비'가 초기 침투구가 되는 전형적 패턴으로, 오늘의 교훈은 **'패치는 냈다가 아니라 적용했다까지 확인하라'**. (→ [[리버스 프록시]] · [[OWASP Top 10]] · [[형상관리]])
