# 📰 IT 신기술 뉴스 — 2026-08-31

> [[2026-08-28]]에서 이어짐. 주말(KST 일요일, 미국 토요일)이라 신규 헤드라인은 얇아, 8/28 이후 8/26~8/28 창의 굵직한 발표를 검증해 정리한다. 축은 셋이다 — ① **엔비디아 Q2 실적이 못 박은 AI 수요**가 **AWS의 GPU 200만 개 추가 조달**로 곧장 이어졌고(칩→인프라 환류 사이클의 재확인), ② 음성·에이전트 쪽에선 **구글 Gemini 3.5 Transcribe**와 **OpenAI의 ChatGPT 라인업 개편**이 나왔으며, ③ 보안에선 **PaperCut 제로데이**·**Next.js 무인증 RCE**·**맨체스터 공항그룹 870만 명 침해**가 한 주를 관통했다.

## 🤖 AI / LLM

- **구글 `Gemini 3.5 Transcribe` 공개 프리뷰(8/26) — STT를 '실시간'과 '녹음' 두 엔드포인트로 쪼갬**: 하나의 모델이 아니라 **`gemini-3.5-transcribe-live`(저지연 스트리밍, 음성 에이전트·자막용)**와 **`gemini-3.5-transcribe`(녹음 파일, 화자 분리·단어 단위 타임스탬프 지원)** 두 엔드포인트로 나와 배포된다. **85개 이상 언어**를 지원하고, Artificial Analysis 측정 기준 **단어오류율(WER) 비스트리밍 2.6% / 스트리밍 4.0%**, 최종 확정까지 시간은 이전 모델 Chirp 3 대비 **70% 단축**. 채움말(filler) 제거·자기수정 처리·커스텀 어휘 인식도 붙었다. (→ [[LLM]] · [[토큰]] · [[REST API]])
- **OpenAI, ChatGPT 라인업 개편 — `o3` 은퇴, `GPT-5.6 Luna` 무료 기본화, `DALL·E GPT` 8/30 종료**: 공식 릴리스 노트 기준 **o3가 90일 일몰 절차를 거쳐 8/26 ChatGPT에서 은퇴**했고, **GPT-5.6 Luna가 무료·Go 사용자 기본 모델**로 내려오며 무제한 텍스트 채팅과 어려운 질문용 'Think' 버튼이 순차 개방된다. **공식 DALL·E GPT는 8/30 종료**(이미지 생성은 기본 모델에 통합), **Codex Remote가 전 플랜 정식 출시(GA)**되어 모바일에서 연결된 Mac·Windows 작업을 이어받아 승인까지 처리한다. (→ [[LLM]] · [[AI 에이전트]] · [[클라이언트 앱]])
- **AWS × 엔비디아, '에이전트·피지컬 AI' 스택으로 확장 — Nemotron 오픈모델·로보틱스까지**: 아래 클라우드 섹션의 GPU 200만 개 조달과 함께 발표된 파트너십의 소프트웨어 축. 엔비디아 **Nemotron 오픈 모델을 Amazon Bedrock·SageMaker**에 올리고, **Amazon Robotics가 엔비디아 플랫폼을 채택**해 물리 세계에서 작동하는 '피지컬 AI/로보틱스'로 범위를 넓힌다. GPU·CPU(Vera)·네트워킹(Spectrum)·데이터 처리(cuDF·cuVS)까지 스택 전반을 묶는 구성이다. (→ [[AI 에이전트]] · [[CUDA]] · [[GPU vs CPU]] · [[LLM]])

## ☁️ 클라우드 / 인프라

- **AWS, 엔비디아 GPU 200만 개 추가 확보(8/26 실적 콜) — 3월 대비 3배, '수요가 예상을 초과'**: **2027~2028년에 걸쳐 Blackwell Ultra·Rubin·Rubin Ultra GPU 200만 개**를 배치한다. 3월에 밝힌 100만 개에 더해 규모를 3배로 키운 것으로, 엔비디아는 "그 이후 수요가 예상을 초과했다"고 밝혔다. 별도로 **연방·국가안보 워크로드(IL6+)용 10만 GPU**를 보안 AWS 인프라에 얹는다. 금액은 미공개. 자체 칩(Trainium)을 미는 AWS가 동시에 엔비디아 물량을 3배로 늘렸다는 점이 핵심. (→ [[GPU vs CPU]] · [[수평 확장]] · [[온프레미스]] · [[nvidia-smi]])
- **엔비디아 Q2 FY27 실적(8/26) — 매출 $96.2B(+106% YoY), 데이터센터 $89.0B(+117%)로 사상 최대**: [[2026-08-28]]에서 'AI 수요 변곡점'으로 예고했던 실적의 실제 숫자다. **전체 매출 $96.2B**(전년比 +106%), **데이터센터 부문 $89.0B**(+117%, 분기 기록)로 이제 **매출의 92%가 데이터센터**에서 나온다. GAAP·비GAAP 총이익률 **75.0%**, 비GAAP EPS **$2.22**, **Q3 가이던스 $108.0B**. Blackwell Ultra 램프업이 성장을 견인했다. (→ [[GPU vs CPU]] · [[수평 확장]])
- **클라우드 점유율 이동 — Google Cloud Q2 2026 15%로 상승, 병목은 여전히 전력**: [[2026-08-28]]의 Synergy Q2 시장 $143B(+43% YoY) 후속 디테일. 집계에 따르면 **Google Cloud가 15%로 상승(AWS 28%·Azure ~20%)**하며 성장률이 가장 가파르다(대략 +60%대). 다만 구도의 병목은 칩이 아니라 **전력·설비** — **대형 변압기 리드타임이 3년을 넘고**, 2026년 발표된 미국 데이터센터 용량의 **30~50%가 지연·취소 위험**이라는 분석이 나온다. (→ [[수평 확장]] · [[서버리스]] · [[온프레미스]])

## 🔐 개발 / 보안

- **PaperCut NG/MF 제로데이 실제 악용 — 인증 우회+RCE 체인, 8/28 긴급 패치**: 인쇄관리 소프트웨어 PaperCut NG·MF에서 **`CVE-2026-81578`(웹 관리 인터페이스 부적절한 접근 제어)**와 **`CVE-2026-82078`(DB 연결 유틸의 안전하지 않은 동적 클래스 로딩)**를 **체인으로 엮어 인증을 우회하고 코드를 실행**하는 공격이 야생에서 관측됐다. **모든 지원 버전**이 영향권이며, 벤더가 아닌 고객 포렌식 팀이 먼저 발견했다. PaperCut는 **8/28 02:10 AEST 긴급 빌드**(v25·26 우선, 이후 v24)를 배포했다. 과거 랜섬웨어 침투구였던 `CVE-2023-27350`을 떠올리게 하는 사안. (→ [[인증과 인가]] · [[OWASP Top 10]] · [[리버스 프록시]])
- **Next.js 긴급 보안 릴리스 — Windows 무인증 RCE `CVE-2026-75604`(CVSS 9.0)와 AVIF 경로**: 주간 4,500만 다운로드 프레임워크에서 두 건이 한꺼번에 패치됐다. **`CVE-2026-75604`**는 **Windows 파일시스템에서 경로 탐색(CWE-22)으로 무인증 RCE**(App·Pages Router 해당, 리눅스·macOS는 미해당), 별도 권고 **`GHSA-2xp9-vwfh-vxw4`**는 **이미지 최적화가 조작된 AVIF를 처리할 때** 상위 의존성 **libheif**를 통한 무인증 RCE다. **15.5.24 / 16.3.3(8/25 배포)**에서 고쳤고, 상위 수정 전까지 **AVIF 최적화는 비활성화**됐다. 자체 호스팅 배포는 즉시 패치가 필요(Vercel 호스팅은 보호됨). (→ [[OWASP Top 10]] · [[HTTP 헤더]] · [[서버리스]])
- **맨체스터 공항그룹(MAG) 침해 — 고객 870만 명 데이터 유출, 랜섬 거부(8/27 확인)**: 맨체스터·스탠스테드·이스트미들랜즈 3개 공항을 운영하는 MAG에서 **약 870만 명의 고객 정보**(이메일·우편번호·차량 등록번호 등, 주차·라운지·Fast Track 예약과 공항 와이파이 등록 데이터)가 유출됐다. **은행계좌·카드 정보는 포함되지 않았고**, 공격자의 **금전 요구는 거부**했다. 승객 안전·공항 운영·항공 보안에는 영향이 없었다고 밝혔으며, 영국 **ICO가 침해 신고를 접수해 조사** 중이다. (→ [[인증과 인가]] · [[OWASP Top 10]] · [[암호화와 해싱]] · [[ISMS]])
