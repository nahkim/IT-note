## 🔐 개발 / 보안

- **CISA, 9/28자로 주간 취약점 게시판(Weekly Vulnerability Bulletin) 폐지 — 심각도 기반→위험 기반(risk-based) 전환, BOD 26-04로 실제 악용·노출 우선, KEV·경보·CVE.org로 대체**: **CISA가 FY26 종료일인 9/28을 끝으로 주간 취약점 게시판을 폐지**한다. 이는 **심각도(severity) 점수 중심에서 실제 악용·노출 증거 등 현실 위험 요인을 우선하는 '위험 기반(risk-based)' 취약점 관리로의 전환**의 일부로, **최근 발령한 구속력 있는 운영지침 BOD 26-04가 연방기관에 점수가 아닌 실제 위험 기준의 우선 조치를 지시**한다. 취약점 정보는 **CVE.org에서 계속 제공**되며, 실무자는 **KEV(알려진 악용 취약점) 카탈로그·CISA 경보/권고·벤더 보안공지**를 활용하도록 권고됐다 — [[2026-09-23]]의 'KEV 무더기 등재' 흐름과 맞물려 **KEV가 사실상 조치 우선순위의 기준선**으로 굳는 장면이다. (→ [[OWASP Top 10]] · [[인증과 인가]])
- **워드프레스 무인증 경로 순회 RCE `CVE-2026-87902`(CVSS 9.2) 공개 수 시간 만에 실제 악용 — `get_page_template()` 로컬 PHP 포함, 4.7.0~7.1.1 영향·7.1.2 등에서 수정, KEV 등재(9/25)·연방 9/28 마감**: 워드프레스 코어의 페이지 템플릿 해석 과정에 **무인증 경로 순회(path traversal)** 결함이 확인됐다. **공격자가 `get_page_template()`가 활성 테마 밖의 읽기 가능한 로컬 PHP 파일을 포함하도록 유도**할 수 있고, **특정 조건에서 원격 코드 실행(RCE)**으로 이어진다(CVSS 9.2). **9/22 패치 공개 후 5시간 이내에 취약 사이트 탐색이 관측**됐고 이후 **셸 명령을 실행할 파일을 디스크에 쓰는 단계까지 진행**됐다. **영향 범위는 4.7.0~7.1.1**로 넓어 **7.1.2(및 7.0.6·6.9.9·6.8.10 등 백포트)로 수정**됐으며, **CISA가 9/25 KEV에 등재하고 연방기관에 9/28까지 조치**를 지시했다. (→ [[OWASP Top 10]] · [[인증과 인가]] · [[HTTP와 HTTPS]] · [[리버스 프록시]])
- **9월 패치 화요일, 973건 사상 최다 CVE·제로데이 2건 — `CVE-2026-85880`(Windows ALPC 권한 상승)·`CVE-2026-81963`(Windows Update Stack 권한 상승) 실제 악용·KEV 등재, Windows 723건·EoP가 절반**: **마이크로소프트 9월 패치 화요일이 973건의 CVE를 수정하며 월간 사상 최다** 기록을 세웠다(Critical 119건 안팎). **실제 악용이 확인된 제로데이 2건**은 **`CVE-2026-85880`(Windows ALPC 권한 상승)과 `CVE-2026-81963`(Windows Update Stack의 파일 접근 전 링크 해석 미흡 권한 상승)**으로, **CISA가 둘 다 KEV에 추가**했다. 취약점은 **Windows 723건·Office 111건·SQL 62건** 등으로 분포하며 **권한 상승(EoP)이 전체의 약 절반**을 차지하고 그다음이 RCE였다 — 전월 대비 약 28~30% 급증한 규모다.
