## 🔐 개발 / 보안

- **Google `Brotli` 디코더 8년 묵은 버그 `CVE-2026-111497`('`Node2Shell`/`HTTP2Shell`', CVSS 9.2) — 압축 요청 하나로 `Node.js`·`Bun`·`Python`·`Envoy`·`Istio` 메모리 오염 — Brotli 1.0.3~1.2.0의 '반환값 미확인'(CWE-252)이 경계 밖 쓰기(CWE-787)로 이어짐(c/dec/decode.c), 공격자가 '불가능한 블록 전환'을 선언하면 스트리밍 디코더가 8바이트 내부 버퍼를 넘겨 공격자 바이트를 계속 쓰며 디코더 상태·프로세스 메모리를 오염, 인증 없는 공격자가 정보 유출·DoS·코드 실행 가능(Imperva가 미패치 Node.js 24.22.0에서 RCE 시연), 고친 버전은 Brotli 1.0.10/1.1.1/1.2.1·Node.js 22.23.4/24.22.1/26.12.1·Bun 1.4.4·Envoy·Istio 등**: **거의 모든 웹 스택이 쓰는 '압축 해제' 경로가 **인증 없이 공격 가능한 공통 공격면**이 된 사례로, [[2026-10-23]]의 eMudhra·PHP2Shell에 이어 '언어·런타임·프록시의 기반 라이브러리'를 **동시에** 패치해야 하는 공급망급 사고다**(Microsoft .NET 보안 권고·Miggo·Phoenix Security·Aikido 확인). (→ [[HTTP와 HTTPS]] · [[HTTP 헤더]] · [[curl]] · [[리버스 프록시]] · [[툴체인]])
- **CISA, `Collabora Online`·`Arista VeloCloud` 실악용 취약점 2건 KEV 추가 — 협업 문서 서버와 SD-WAN 오케스트레이터가 공격 표적 — 10/24 발표: ① `CVE-2026-110447`(CVSS 9.2)은 NextCloud 안에서 쓰이는 Collabora Online 내장 CODE 서버의 OS 명령 주입으로 `proxy.php`를 통해 RCE 가능(9월 26.4.303에서 수정), 공격자가 웹셸을 심어 자격증명 저장소·비밀번호 관리자·암호화폐 지갑을 수색한 정황 포착 ② `CVE-2026-114625`(CVSS 9.9)는 온프레미스 Arista VeloCloud Orchestrator의 SQL 주입으로 권한 내부 기능 접근 가능(10월 5.2.3.18/6.1.3.10/6.4.2.12에서 수정, 악용에는 VCO 웹 접근+인증 세션 필요)**: **인터넷에 노출된 '협업·네트워크 관리' 제품이 뚫리면 내부 자격증명·망 전체로 번지므로, KEV 등재는 **연방기관 의무 패치 + 모두의 즉시 패치** 신호다**(The Hacker News·Security Affairs·cvefeed 확인). (→ [[OWASP Top 10]] · [[인증과 인가]] · [[WAF]] · [[셀프호스팅]] · [[리버스 프록시]])
- **`LiteLLM` 공급망 사고 — 유출된 마스터 키가 악성 `PyPI`(1.107.0)·Docker 배포로 — AI 게이트웨이가 백도어가 된 사례 — 2026-05-27 공개 리포(LiteLLM-Labs/lite-harness)에 Agent Platform 마스터 키가 담긴 설정파일이 커밋됨, 즉시 force-push로 덮었으나 키 폐기(revoke)는 안 됨, 공격자가 10/10 그 미폐기 키로 Agent Platform에 접근해 GitHub CLI OAuth 토큰을 탈취→릴리스 파이프라인을 장악, LiteLLM 1.107.0 PyPI 휠·Docker 이미지가 파이썬 시작 시 자격증명 탈취기를 실행하고 추가 코드를 받아 실행하도록 오염(현재 PyPI 격리·악성 Docker 이미지 제거)**: **'LLM 여러 개를 묶는 AI 게이트웨이'처럼 많은 비밀을 쥔 인프라가 **한 번의 키 유출+미폐기**로 설치형 백도어가 될 수 있음을 보여준다 — 핵심 교훈은 '유출된 비밀은 덮기(force-push)가 아니라 즉시 폐기'다**(The Hacker News·Socket·Snyk·LiteLLM 공식 확인).
