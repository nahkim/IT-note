## 🤖 AI / LLM

- **오픈AI, ChatGPT 광고에 대화형 `Sponsored Agents` 도입(9/16) — 브랜드가 운영하는 '광고 에이전트'와 사용자가 직접 대화·후속질문·자사 사이트 이동, HubSpot·Shopify(미국) 연동으로 광고 생성·성과·리드 관리, 광고는 무료·Go 티어에 노출·답변과 분리·광고주는 대화 내용 못 봄, 광고 사업 200일 미만에 연환산 $1B run rate·연 $2.5B 목표**: 오픈AI가 **ChatGPT 광고에 새 형식 `Sponsored Agents`(테스트)**를 붙였다. 관련 광고가 뜨면 사용자는 **명확히 표시된 '브랜드 운영 에이전트'와 별도 대화**를 열어 원하는 조건을 말하고 후속 질문을 던진 뒤 준비되면 업체 사이트로 넘어갈 수 있다 — **이 대화는 ChatGPT의 독립 답변·원래 대화와 분리**된다. 같은 날 **HubSpot 고객은 ChatGPT 광고 계정을 연결**해 HubSpot 안에서 광고를 만들고, **미국 Shopify 판매자는 App Store의 ChatGPT Ads 앱**으로 캠페인을 운영할 수 있게 됐다. 광고는 **무료·Go 티어에 노출**되고 **답변 생성과 섞이지 않으며 광고주는 사용자의 사적 대화를 볼 수 없다**. 오픈AI 광고 사업은 **200일도 안 돼 연환산 매출 $1B run rate**에 도달했고(8/31 공개) **올해 $2.5B**를 목표로 한다. - **AI 에이전트 'skills'가 공급망 공격의 새 표면 — AIR 리포트, 라이브 skill 142,836개 스캔서 17,822개(12.4%)가 신뢰 못 할 외부 리소스 참조(갓 등록된 도메인·거의 안 쓰인 GitHub 계정·방치된 호스팅), 앤스로픽·오픈AI 사칭 skill이 플랫폼 심사 우회·설치 즉시 임의 코드 실행 가능·6.7M 설치 규모**: AI 에이전트에 능력을 끼워 넣는 **'skills'(스킬 애드온) 생태계가 심사 없는 공급망**이 되고 있다는 경고가 나왔다. 보안업체 **AIR가 라이브 skill 142,836개를 스캔**한 결과 **17,822개(약 12.4%)가 최소 하나 이상 '신뢰할 수 없는' 외부 리소스에 의존**했는데, 판별 신호는 **갓 등록된 도메인·거의 사용되지 않은 GitHub 계정·방치된 호스팅** 등이다. 특히 **앤스로픽·오픈AI 등 신뢰 브랜드를 사칭하도록 만들어 플랫폼 검수를 통과**하고 **설치되면 임의 코드를 실행**할 수 있는 skill도 확인됐다(누적 설치 6.7M 규모 보도). 브라우저 확장·패키지 레지스트리에서 봤던 **'신뢰된 마켓 = 안전' 착각**이 AI 에이전트로 그대로 옮겨온 셈이다. (→ [[AI 에이전트]] · [[OWASP Top 10]] · [[브라우저 확장 프로그램]] · [[프롬프트 엔지니어링]])
- **CSA, "AI는 이제 클라우드 위협의 무기이자 표적"(9/17) — Top Threats to Cloud Computing 2026에서 `AI-Enhanced Attacks`(2위)와 `AI System Compromise`(6위)를 별개 범주로 분리, 공격자는 AI로 피싱·정찰·악성코드·취약점 발견·측면이동을 가속, 방어자가 배포한 AI(모델·프롬프트·데이터)는 조작·탈취 대상, 1위 위협은 여전히 부실한 IAM(과다권한·비인간 신원·자격증명)**: 클라우드 시큐리티 얼라이언스(CSA)가 **AI가 클라우드 위협 지형을 양방향으로 바꿨다**고 정리했다. **① `AI-Enhanced Attacks`(2026 위협 2위)** — 공격자가 AI로 **피싱·정찰·악성코드 개발·취약점 발견·자동화·측면이동**을 더 빠르고 정교하게 만들고, **② `AI System Compromise`(6위)** — 조직이 배포한 **AI 시스템 자체(모델·프롬프트·데이터)가 조작·열화·무단제어의 표적**이 된다. 두 위협을 **처음으로 별개 범주로 분리**한 것이 이번 보고서의 핵심이며, **1위 위협은 여전히 부실한 IAM**(과다 권한·비인간 신원·관리 안 된 자격증명·연합 신뢰)이다 — 앞선 AIR·도커 사례가 모두 이 지형 안에 놓인다.
