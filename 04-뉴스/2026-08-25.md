# 📰 IT 신기술 뉴스 — 2026-08-25

> [[2026-08-21]]에서 이어짐. 지난주가 '모델 통제·AI가 쓴 익스플로잇'이었다면, 이번 주는 **에이전트 표준의 통합**, **AI 기업의 첫 흑자**, 그리고 **개발 플랫폼(코드 저장소·메일 서버·패키지 생태계)을 정조준한 실제 악용**이 겹친 주다.

## 🤖 AI / LLM

- **Google의 A2A 프로토콜, 리눅스재단 산하 Agentic AI Foundation(AAIF)에 합류 — 에이전트 프로토콜 계층이 한 지붕 아래로**: 8월 중순~20일, A2A(Agent2Agent)가 Anthropic이 기증한 **MCP**와 나란히 중립 거버넌스로 들어갔다. AAIF는 창립 49곳에서 **250곳 이상**(AWS·Google·Microsoft·OpenAI·Anthropic·Cloudflare·Bloomberg 등)으로 1년 만에 성장. 역할 분담이 명확해졌다 — **MCP는 에이전트↔도구(수직)**, **A2A는 에이전트↔에이전트(수평)**. 멀티벤더 에이전트 조합의 통합 비용이 낮아진다는 의미. (→ [[AI 에이전트]] · [[API 게이트웨이]])
- **Anthropic, 프런티어 AI 중 이례적으로 '흑자 분기' — 2분기 매출 $11.5B+·첫 (조정)영업흑자**: 8/15 보도 기준 지난 분기 매출이 **$11.5B 초과**(1분기 $4.73B, 전년 동기 $787M 대비 14배 이상)로 뛰었고, 회사 역사상 처음으로 **양(+)의 조정 영업이익**을 냈다고. 같은 흐름에서 **Claude Android 앱**을 정식 출시해 웹·iOS·Android 전 플랫폼에서 비전·다국어·추론을 지원하게 됐다. "성장은 빠른데 적자"라는 통념이 흔들리는 신호. (→ [[LLM]] · [[AI 에이전트]])
- **Google Gemini 3.7 Flash 공개(8/13) — '코딩·에이전트용 일꾼 모델'을 반값에**: 100만 토큰 컨텍스트, 도입가 **$0.75/$3.75(입력/출력, 100만 토큰)** 로 직전 3.6 Flash의 약 절반(2026년 말까지 고정). 자체 벤치 **DeepSWE 49.0→65.3%**. 배경으로 **Gemini 앱 월 활성 사용자 10억 명 돌파(8/11)** 소식도. 경쟁축이 플래그십 성능 자랑에서 **원가·에이전트 실전 성능**으로 옮겨간 흐름과 맞물린다. (→ [[토큰]] · [[프롬프트 엔지니어링]] · [[LLM 모델 이름 읽는 법]])

## ☁️ 클라우드 / 인프라

- **Nvidia, 데이터센터 개발사 Cloverleaf 지분 인수(8/21) — 자기 칩을 살 인프라에 직접 투자**: Cloverleaf는 전력회사와 데이터센터를 잇는 '중개자'로, Nvidia는 소수 지분(수억 달러 규모, 구체 조건 비공개)을 확보했다. 같은 주 **SB Energy에 $1.5B** 투자도. 칩 제조사가 칩을 소비할 생태계에 직접 자금을 대 **"AI 플라이휠"**을 스스로 돌리는 전략의 연장. (→ [[온프레미스]] · [[수평 확장]])
- **Nvidia, OpenAI 오하이오 데이터센터에 최대 $105B 융자(8/17 SEC 공시) — 규모는 크되 '순환 융자' 회의론도 확대**: 초기 **4.25GW + 옵션 3.75GW**(합 8GW), SB Energy가 20년 리스로 건설·운영하고 SoftBank와 함께 **10GW 전력·그리드에 최소 $4.2B**를 투자한다. 2028년 단계 가동, 건설 일자리 3.5만. 다만 Fortune은 확정 규모가 앞서 보도된 수치보다 **약 $145B 낮게** 잡혀 "인위적 수요" 우려를 키운다고 짚었다. (→ [[온프레미스]] · [[GPU vs CPU]])
- **Amazon, 인도 하이데라바드 신규 데이터센터 착공 — 2030년까지 총 $48B(클라우드·AI 인프라 $21B+)**: 앞서 발표한 $35B에 **$13B를 더해** $48B로 상향했고, Mumbai·Hyderabad의 AWS 데이터센터 용량을 키운다. 커스텀 AI 칩·관리형 AI 서비스를 인도 스타트업·기업·정부에 제공하는 게 목표. 하이퍼스케일러의 인도 거점 경쟁이 본격화. (→ [[수평 확장]] · [[온프레미스]])

## 🔐 개발 / 보안

- **CISA, Zimbra 원격 코드 실행 취약점 `CVE-2026-73570`(CVSS 8.9) 긴급 등재 — 연방기관 패치 기한 8/24**: `zimbra-snmp` 패키지가 깔려 SNMP 알림이 켜진 **ZCS 10.1.20 미만**에서, **미인증** 공격자가 조작된 SMTP 요청으로 Zimbra 사용자 권한의 **임의 OS 명령**을 실행할 수 있다(입력 미정제). **CERT Polska가 8/19 실제 악용을 최초 포착**, Shadowserver는 **270곳 이상 침해**를 확인했고 Head Mare가 PhantomCore 유포에 이용. 패치본은 7/20 나온 **10.1.20**. (→ [[OWASP Top 10]] · [[인증과 인가]])
- **npm 공급망 웜(keyv·cacheable 계열) 확산 — 444개 패키지·월 20억 설치 오염**: 유지관리자의 GitHub 계정 탈취를 발판으로, `preinstall` 훅(`setup.mjs`)을 심어 **`npm install`만으로 자동 실행**되는 자격증명 탈취 웜이 flat-cache(월 5.65억)·file-entry-cache 등 인기 캐싱 라이브러리 전반으로 번졌다. 웜은 발견한 GitHub 토큰으로 접근 가능한 저장소·브랜치에 악성 코드를 **재커밋해 자가전파**한다. GitHub는 OAuth·앱 토큰까지 **셀프서비스 폐기 API**를 확대 대응. (→ [[형상관리]] · [[Git]] · [[환경 변수]] · [[CI-CD]])
- **개발 플랫폼이 표적 — GitLab 코드 인젝션 활발한 악용, Keycloak 계정 탈취 결함 긴급 패치(8/22 브리핑)**: GitLab `CVE-2026-19478`(CVSS 9.4)은 공개 며칠 만에 실제 악용에 들어가, 미인증 공격자가 GraphQL 지시자로 **공개 프로젝트를 수정·삭제·재작성**할 수 있다. 또 Red Hat·Keycloak은 미인증 원격 공격자가 **비밀번호 재설정을 강제해 임의 계정을 탈취**할 수 있는 `CVE-2026-18963`(CVSS 9.1)을 패치했다(현재까지 악용·공개 익스플로잇 미확인). 코드 저장소와 신원관리(IAM)가 나란히 노려진 셈. (→ [[OAuth]] · [[인증과 인가]])
