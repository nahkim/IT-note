# 📰 IT 신기술 뉴스 — 2026-08-27

> [[2026-08-26]]에서 이어짐. 어제가 'AI 플랫폼 정리 데이'(OpenAI `o3`·Assistants API 은퇴)였다면, 오늘의 축은 **Nvidia 실적이 못 박은 'AI 수요 변곡점'**이다 — 데이터센터 매출 $89B로 전체의 92%를 채우며 다음 분기 $108B를 예고했다. 소프트웨어 쪽에선 **에이전트 표준의 통합**(A2A가 MCP 옆으로)과 **음성 AI의 세대교체**(Gemini 3.5 Transcribe)가, 보안 쪽에선 **'열린 등록(open registration)'이 곧 원격 코드 실행이 되는** 개발 인프라 취약점(Gitea·쿠버네티스)이 겹쳤다.

## 🤖 AI / LLM

- **Google, `Gemini 3.5 Transcribe` 공개(8/26) — 음성 인식이 '받아쓰기'에서 '정리된 글'로**: 85개 이상 언어를 자동 감지하는 고정밀 STT 모델로, 배경 소음·전문 용어에 강하고 'um·어…' 같은 군말을 걷어내 자동 서식화까지 한다. **비스트리밍용 `gemini-3.5-transcribe`**와 **Live API로 WebSocket 양방향 스트리밍하는 `gemini-3.5-transcribe-live`** 두 종으로, Gemini API(AI Studio)에 공개 프리뷰로 올라왔고 Android·macOS(Gboard Rambler)와 곧 Chrome에도 들어간다. 실시간 자막·회의록·음성 에이전트의 입력단이 한 단계 정밀해졌다. (→ [[LLM]] · [[WebSocket]] · [[토큰]])
- **OpenAI, ChatGPT Business에 'Premium 좌석'·업무용 기능 확장(8/25) — 기업 과금과 에이전트화가 동시에**: 표준 좌석의 **5배 사용량·5시간 제한 없음**을 주는 **Premium 좌석(연 결제 시 $100/사용자·월, 월 결제 $125)**을 도입했다. 함께 **로그인이 필요한 사이트를 ChatGPT가 계정정보를 보지 않고 대신 처리**하는 업무용 기능과, **Slack·Gmail·GitHub의 변화에 반응해 실행되는 예약 작업(Scheduled tasks)**을 Plus·Pro에 열고 Free에도(3개 제한) 굴리기 시작했다. '대화형 비서'에서 '이벤트에 반응하는 일꾼'으로 넘어가는 흐름. (→ [[AI 에이전트]] · [[REST API]] · [[인증과 인가]])
- **에이전트 표준 통합 가속 — Google `A2A`가 Linux Foundation의 Agentic AI Foundation(AAIF)에 합류, MCP와 한 지붕**: 에이전트끼리 통신·협업하는 **A2A**(Agent2Agent)가, Anthropic이 기증한 **MCP**(에이전트↔도구·데이터 연결)와 나란히 중립 재단 관리로 들어갔다. 재단은 1년도 안 돼 창립 49곳→**250곳 이상**으로 커졌고, 플래티넘 멤버에 AWS·Anthropic·Google·Microsoft·OpenAI가 모두 이름을 올렸다. 'A2A는 에이전트 사이, MCP는 에이전트와 도구 사이'로 역할이 갈리며 상호운용 표준이 굳어지는 중. (→ [[AI 에이전트]] · [[RAG]] · [[REST API]])

## ☁️ 클라우드 / 인프라

- **Nvidia, FY27 2분기 실적 발표(8/26) — 매출 $96.2B, 데이터센터 $89.0B, 다음 분기 $108B 예고**: 7/26 마감 분기 매출이 **전년比 +106%·전분기比 +18%**로 $96.2B, 그중 **데이터센터가 $89.0B(전체의 ~92%, 전년比 +117%)**를 차지했다. GAAP 매출총이익률 75.0%, 희석 EPS는 GAAP $2.46·non-GAAP $2.22. 3분기 가이던스로 **$108.0B(±2%)**를 제시해 시장 컨센서스(~$103.8B)를 웃돌았다. 젠슨 황은 "AI가 변곡점에 도달했다 — 유용한 일을 하기 시작했다"고 표현. (→ [[GPU vs CPU]] · [[CUDA]] · [[nvidia-smi]])
- **같은 실적의 이면 — 이번 분기 中 H20 매출 '0', 대신 Blackwell Ultra 풀가동 램프**: 지정학 규제로 **분기 중 중국향 H20 판매가 사실상 전무**했음에도 데이터센터가 초고성장한 건 **Blackwell**(차세대 아키텍처) 수요 덕. CFO Colette Kress는 라이선스 문제가 풀리면 **3분기 중국향 H20이 $20~50B**에 이를 수 있고 일부 중국 고객이 최근 라이선스를 확보했다고 밝혔다. 수요는 넘치는데 병목은 '기술'이 아니라 '규제·공급'이라는, 어제 정리한 자본지출 서사와 같은 결. (→ [[온프레미스]] · [[수평 확장]])
- **이 돈이 향하는 곳 — 데이터센터가 매출의 92%, [[2026-08-26]]의 '$725B 하이퍼스케일러 capex'가 실제로 착지하는 지점**: 어제 Amazon $220B·4사 합 $725B로 요약한 인프라 투자 사이클이 결국 **가속기 매출로 환류**되고 있음을 이번 실적이 수치로 보여준다. 전력·부지·칩 공급이 병목인 상황에서, 클라우드 수요→GPU 매출→다시 데이터센터 증설로 도는 순환이 당분간 이어질 전망. (→ [[수평 확장]] · [[온프레미스]] · [[GPU vs CPU]])

## 🔐 개발 / 보안

- **CISA, Gitea `CVE-2026-60004`(CVSS 9.8) KEV 등재(8/25) — '열린 등록'이 곧 무인증 RCE, 연방기관 기한 8/28**: 셀프호스팅 Git 서비스 Gitea의 **`diffpatch` API 취약점**으로, 저장소 쓰기 권한만 있으면 악성 **Git 훅**을 심어 **Gitea 서비스 계정 권한으로 임의 셸 명령**을 실행할 수 있다. 문제는 Gitea가 기본적으로 **공개 회원가입(open registration)**을 켜 둬, 미인증 사용자가 계정·저장소를 만들어 그대로 악용할 수 있다는 점. 이미 노출된 인스턴스에 **암호화폐 채굴형 페이로드**를 심은 사례가 관측됐고, 수정본은 1.27.1. (→ [[Git]] · [[형상관리]] · [[OWASP Top 10]] · [[인증과 인가]])
- **Red Hat, 관리형 쿠버네티스 SSRF `CVE-2026-66794`(CVSS 9.3) 공개(8/19) — 인증 없이 내부 클러스터 서비스에 도달**: Multicluster Engine의 **`cluster-proxy-addon`** 컴포넌트에서, 인증·인가가 빠진 사용자 대면 Route를 통해 **미인증 공격자가 SSRF**로 관리 대상 클러스터들의 **외부 미노출 내부 서비스에 프록시 요청**을 보낼 수 있다. 내부 API 열람·민감 데이터 회수·내부 엔드포인트 정찰이 가능해, 다중 클러스터 관리 평면이 뚫리면 그 아래 워크로드가 통째로 위험해진다. (→ [[쿠버네티스]] · [[마이크로서비스]] · [[API 게이트웨이]] · [[인증과 인가]])
- **배경이 된 공급망 사고 — `keyv`·`cacheable` 계열 npm 웜(8/4~) 여파 지속: 444개 패키지·월 20억+ 설치 오염**: 유지관리자 GitHub 계정 탈취로 시작돼 **`preinstall` 훅**이 npm·GitHub·AWS 토큰을 훔치고 스스로 다른 패키지로 번지는 웜이, 주당 1.27억 다운로드의 `keyv`를 포함해 **444개 패키지(1,381개 버전)**를 감염시켰다. 특히 악성 커밋을 main에 밀어 넣고 곧바로 릴리스해 **GitHub Actions로 정상 서명(provenance)된 버전**이 배포된 점이 뼈아프다. Gitea 건과 묶어 보면, 오늘의 교훈은 하나 — **'출처(가입·서명·훅)를 믿지 말고 검증하라'**. (→ [[CI-CD]] · [[형상관리]] · [[환경 변수]] · [[OWASP Top 10]])
