# 📰 IT 신기술 뉴스 — 2026-08-20

> ⚙️ 자동 스케줄러 실패로 8/21에 뒤늦게 백필한 노트. 검증은 정상 수행.

## 🔐 개발 / 보안 (오늘의 핵심 — CVSS 9점대 화상회의 서버가 실악용)

- **CISA KEV, TrueConf Server 2종 추가 — 미인증 원격 코드 실행**: `CVE-2026-72529`(중요 기능 인증 누락, **CVSS 9.8**)와 `CVE-2026-72530`(코드 인젝션, **CVSS 9.0**)이 실악용으로 등재됐다. 둘 다 **TCP 4307 포트**에 접근 가능한 미인증 원격 공격자가 임의 스크립트를 실행하거나 격리 환경을 탈출해 호스트에서 코드를 실행할 수 있다. 실제로 **PhantomCore 악성코드 유포**에 쓰였다. 영향: 5.3.x~5.3.9, 5.4.x~5.4.9, 5.5.x~5.5.5 이전 / 패치본: **5.3.9·5.4.9·5.5.5**. 이번 주에만 KEV에 **6건**이 올랐다. (→ [[웹사이트 보안]] · [[인증과 인가]] · [[리버스 프록시]])
- **Siemens S7 권고 후속 — "이론적 위험이 아니다"**: [[2026-08-18|8/18 합동 권고]]에 대한 분석 기사들이 이날 이어졌다. 요지는 **AI가 익스플로잇 작성 비용을 낮춘 결과가 이미 물리 설비 피해로 나타났다**는 것. 노출된 PLC 목록화와 인터넷 차단이 여전히 1순위 조치. (→ [[온프레미스]] · [[웹사이트 보안]])
- **Munich Re, 사이버보험사 At-Bay를 기업가치 $575M에 인수** — At-Bay는 **미국 사이버보험 시장 약 5%**를 점유한다. 사이버 위험이 재보험사가 직접 사들일 만큼 **가격이 매겨지는 자산**이 됐다는 신호. (→ [[ISMS]] · [[성능 SLA]])

## 🤖 AI / LLM

- **Stripe×OpenRouter 인수 확정 — 약 $7.5B(창업자 $1.5B·투자자 $6B)**: 창업 3년, 5월 기업가치 **$1.3B**였던 회사다. OpenRouter는 **400개 이상 모델을 하나의 API로 중계**하는 게이트웨이로 **하루 10조 토큰 이상**을 처리한다. 결제 회사가 이걸 사는 논리는 단순하다 — **"어느 모델을 쓸지 고르고, 쓴 만큼 정산한다"**는 문제가 곧 결제 문제다. (→ [[API 게이트웨이]] · [[토큰]] · [[LLM 모델 이름 읽는 법]])
- **OpenAI 학습 보류 지속** — [[2026-08-19|어제 공식화]]된 최대 규모 학습 중단이 이어지는 중. 모니터링 강화로 **연산 비용 약 20% 증가**를 감수한다. (→ [[LLM]])
- **다중 에이전트가 실제 공격에 쓰였다** — 아시아·태평양 공격 사례에서 정찰·익스플로잇에 **최대 8개 AI 에이전트를 동시 운용**한 프레임워크가 관측됐다. (→ [[AI 에이전트]])
