- **Google, Gemini 3.7 Flash 출시(8/13) — 코딩 점수 급등 + 도입가 50% 인하**: FrontierCode 1.1 **34.4% → 43.6%**, DeepSWE v1.1 **49.0% → 65.3%**로 3주 전 3.6 Flash 대비 크게 뛰었다. 가격은 **$0.75/M 입력·$3.75/M 출력**인데 이건 **2026-12-31까지 도입가**이고, 2027-01-01부터 **$1.50/$7.50으로 2배**가 된다. 모델 크기나 컨텍스트(100만 토큰)를 늘려서가 아니라 **알고리즘 개선으로** 올린 성능이라는 점이 핵심. (→ [[LLM]] · [[토큰]] · [[LLM 모델 이름 읽는 법]])
- **DeepSeek는 거꾸로 — V4 Pro API 최대 1,100% 인상(8/16 시행)**: 3개월간 **$0.87/M**였던 V4 Pro 출력 토큰이 **피크 $3.96 / 오프피크 $1.98**로, 캐시 미스 입력은 **$0.435 → $1.32**(피크). 피크 시간대는 **01:00~04:00·06:00~10:00 UTC**. "자원을 더 합리적으로 배분"한다는 명분이지만, 실질은 **혼잡 시간대를 가격으로 밀어내는 것**이다. 싼 API에 얹은 서비스는 원가 구조가 하루아침에 바뀔 수 있다는 교훈. (→ [[토큰]] · [[API 게이트웨이]] · [[트레이드오프]])
- **속도 자체가 상품이 되다 — OpenAI×Cerebras 초고속 GPT-5.6 Sol**: 최대 **14배 빠른** 응답, **초당 750토큰** 출력으로 일부 API 고객에 프리뷰 제공. 같은 모델을 **어느 하드웨어에 얹느냐**가 차별점이 되는 국면. (→ [[GPU vs NPU]] · [[vLLM]])
- **Z.ai GLM-5.3 공개 — 오픈웨이트가 보안 벤치마크에서 프런티어에 근접**: CyberGym **84.5%**로 Anthropic Mythos 5(83.8%)를 앞섰으나, 익스플로잇 개발은 **54.4% vs 78%**로 격차가 남았다. 고위험 기능은 **신뢰 기반 접근 제어**로 공개할 계획. (→ [[로컬 LLM과 셀프호스팅]] · [[파인튜닝]])
