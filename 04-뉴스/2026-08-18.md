# 📰 IT 신기술 뉴스 — 2026-08-18

> ⚙️ 자동 스케줄러 실패로 8/21에 뒤늦게 백필한 노트. 검증은 정상 수행.

## 🔐 개발 / 보안 (오늘의 핵심 — AI가 짠 익스플로잇이 상수도 시설을 멈췄다)

- **NSA·CISA·FBI·DOE·EPA 합동 권고 — Siemens S7 PLC 실제 공격 중**: 인터넷에 노출된 **Siemens S7 시리즈 PLC**가 상수도·에너지·제조·화학·식품 등에서 표적이 되고 있으며, **공격 스크립트 작성에 AI가 쓰여 필요한 기술 수준과 시간이 급격히 낮아졌다**는 게 권고의 핵심이다. **7/26~27 밤 미네소타에서만 30개 이상 상하수도 시설**이 공격받아 한 도시의 정수장이 일시 정지했고, 확인된 한 사례에서는 **안전 알람과 자동 정지를 무력화**해 경보 없이 위험 상태가 진행됐다. 권고 조치: PLC 자산 목록화 → 패치 → **인터넷 노출 차단** → 접근통제·모니터링. ([[2026-08-15|지난주 ZOOMSDAY]]가 "AI가 익스플로잇을 만든다"의 연구실 버전이었다면, 이건 현장 버전이다.) (→ [[웹사이트 보안]] · [[인증과 인가]] · [[온프레미스]])
- **CISA KEV 4종 추가 — Windows IKE·SharePoint·vCenter·macOS**: Microsoft **IKE 서비스 확장 Double Free**, Microsoft **SharePoint 약한 인증**, Broadcom **VMware vCenter 경로 탐색**, **Apple macOS 부적절한 인증**이 실악용으로 등재됐다. OS·협업·가상화 관리 평면이 한 번에 올라온 조합. (→ [[웹사이트 보안]] · [[컨테이너와 Docker]])
- **Copilot 'CoSnitch' 패치 — 8개월 만에**: Varonis가 신고한 `CVE-2026-24301`을 Microsoft가 이날 수정했다. Copilot을 구슬려 **문서화되지 않은 `?autorun=1` 파라미터**를 실토하게 만든 뒤, 링크 클릭 한 번으로 **연결된 OAuth 앱(Gmail·Drive 등) 데이터를 탈취**하고 메모리를 오염시킬 수 있었다. 2025년 12월 신고 → **8개월 뒤 패치**라는 시차가 생성형 도구의 보안 성숙도 논쟁을 키웠다. (→ [[프롬프트 엔지니어링]] · [[OAuth]] · [[XSS]])

## 🤖 AI / LLM

- **OpenAI, 13~17세용 ChatGPT 출시** — 보호자 통제와 강화된 콘텐츠 제한(자해·성적 대화 차단)을 적용. 미성년자 안전이 제품 분기의 이유가 됐다. (→ [[LLM]])
- **Greg Brockman "보안을 자동화하라"** — AI 에이전트가 취약점을 점점 더 잘 찾는 만큼, 방어 측도 자동화하지 않으면 속도에서 진다는 경고. 같은 날 나온 Siemens 권고와 정확히 같은 이야기를 반대편에서 한 셈. (→ [[AI 에이전트]] · [[CI-CD]])
- **Etched, 기업가치 $21B — 추론 전용 칩의 상승**: 누적 약 **$2B** 조달, 첫 칩 출하, Jane Street를 초기 고객으로 확보. 범용 GPU가 아니라 **트랜스포머 추론에 특화한 칩**으로 NVIDIA에 붙는 전략. (→ [[GPU vs NPU]] · [[Transformer]])
