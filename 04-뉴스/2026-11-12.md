- **`SAP` 11월 보안 패치데이(11/10), CVSS `10.0` 만점 4건 일괄 수정 — `ICM2SHELL`(`CVE-2026-76964` NetWeaver ICM + `CVE-2026-89126` Web Dispatcher·동일 근본원인·메모리 손상→사전인증 RCE), HTTP/HTTPS/WebSocket 처리 계층 급소, Onapsis 발견** — `SAP`가 **11/10 월례 보안 패치데이에서 35개 보안노트·4개 GitHub 권고**를 내며 **CVSS 10.0(최고 심각도) 결함 4건을 수정**: 핵심은 **`ICM2SHELL`로 묶이는 한 쌍 `CVE-2026-76964`(NetWeaver AS ABAP의 `ICM`·인터넷 커뮤니케이션 매니저)와 `CVE-2026-89126`(Web Dispatcher)**로, **같은 근본 원인의 메모리 손상 결함**이며 **인증 없이(pre-auth) 원격 코드 실행(RCE)**이 가능함: **`ICM`/`Web Dispatcher`는 SAP가 `HTTP`·`HTTPS`·`WebSocket` 트래픽을 처리하는 최전방 계층**이라, 결함이 뚫리면 **인증 과정을 건너뛰고 서버를 장악**할 수 있음(발견: `Onapsis`·수정: Note 3778530/3778556): **[[2026-11-11]]의 'MS 패치 홍수'에 바로 이어 'ERP 심장부가 무인증으로 노출'된 급소 — 경계면(HTTP 프록시) 노출 서버는 즉시 패치해야 하며, 아직 실악용은 관측되지 않아 지금이 패치 적기**다(점수·상세는 SAP/Onapsis 기준). - **같은 패치데이에 `PROXYGATE`(`CVE-2026-89103`)·SAML 인증 우회도 CVSS `10.0` — 공유 인프라(프록시) 악용·인증 전면 우회, "실악용 전 패치창(window)" 강조** — SAP 11월 패치의 나머지 두 만점 결함: **`PROXYGATE`(`CVE-2026-89103`)**는 **공유 프록시/게이트웨이 경로를 악용**해 무단 접근을 허용하고, **별도의 SAML 인증 우회 결함(CVSS 10.0)**은 **싱글사인온(SSO) 인증을 통째로 건너뛰게** 함: 네 결함 모두 **인증 없이 '전체 시스템 접근'**으로 이어질 수 있어, 보안기관들은 **"아직 야생 악용이 없을 때가 패치 비용이 가장 싸고 사고가 없는 창"**이라고 못 박음: **[[2026-11-11]]의 'Exchange 이메일 한 통 RCE'와 결이 같은 — 인증·경계면을 무력화하는 만점 결함이 ERP·웹디스패처로 번진** 국면이다(스코어·분류는 SAP/Onapsis·DEV 기준·일부 매체는 SAML 건을 별개 노트로 집계). - **`PolinRider` 악성 로더, npm 패키지 10개(릴리스 12개) 탈취 — 이더리움 블록체인을 C2 은닉처(dead drop)로, 공개 RPC로 C2 IP 조회·인메모리 실행, 주당 ~1,400 다운로드 영향** — `OX Security`·`Sonatype` 연구진이 **11월 들어 정상 npm 패키지들이 `PolinRider` 악성코드 계열로 변조된 사례를 적발**: **탈취된 10개 패키지의 12개 릴리스**에 **숨은 런타임 로더**가 심겨, 패키지를 import하면 **공개 이더리움 RPC 엔드포인트를 조회해 블록체인 트랜잭션에 인코딩된 C2 IP를 복원**(11/3 관측 시 `95.135.181.151`)하고 **인메모리로 추가 페이로드를 실행**함 — **블록체인을 '없앨 수 없는 C2 주소록(dead drop)'**으로 쓰는 수법: 영향 패키지는 **합산 주당 약 1,400 다운로드** 규모이며, npm 악성코드는 2025년 2배 이상 급증해 **오픈소스 악성코드의 ~90%**를 차지(ReversingLabs): **[[2026-11-10]]의 'FFmpeg 메모리 안전'·[[2026-11-09]]의 'WordPress RCE'와 같은 줄기 — 개발자가 매일 당기는 '의존성'이 상시 공급망 급소가 된** 국면으로, 잠금파일(lockfile) 고정·설치 스크립트 차단이 방어선이다(IoC·수치는 OX/Sonatype/GBHackers 기준).
