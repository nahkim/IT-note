## 🔐 개발 / 보안

- **리눅스 커널 TCP use-after-free `CVE-2026-98432`(CVSS 9.8), AI가 쓴 무인증 원격 루트 익스플로잇으로 — `Anthropic` 내부 `Claude` 연구 모델이 약 53분 만에 작성 — 10/27 공개·11/1 광범위 보도: IPv4 TCP 연결 수립(특히 `MPTCP` 리스너) 중 IP 옵션(`ireq_opt`)을 복사 없이 넘겨 RCU로 접근 가능한 객체를 `kfree`로 해제하는 **use-after-free**로, 재전송 SYN/syncookie 경로가 해제된 메모리를 건드려 **무인증·zero-click 원격 코드 실행**이 가능, `Anthropic`은 10/27 **미공개 내부 `Claude` 연구 모델이 KASLR 우회→콜백 포인터 덮어쓰기로 약 53분 만에 원격 루트 셸을 얻는 작동 익스플로잇을 작성**했다고 공개, **업스트림 2줄 패치는 10/5 반영**됐으나 **RHEL·Ubuntu 안정 커널은 10/30 기준 미출시**, 공개 익스플로잇 코드·실악용은 아직 미관측**: **[[2026-10-31]]의 '위장 Claude Code 확장 SSH 백도어'가 사람 공격자의 공급망 침투였다면, 이번엔 **AI 모델이 커널 0-day 익스플로잇을 직접 작성**해 방어·공격 양측의 자동화 속도가 뒤바뀌는 전환점을 보여준다 — 유지보수 안정 커널의 즉시 패치가 핵심**(TuxCare·BleepingComputer·CybersecurityNews·Aikido 확인).
