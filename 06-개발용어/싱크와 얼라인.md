# 싱크와 얼라인 (Sync / Align)

**한 줄 뜻**: **싱크**는 서로 아는 내용을 같게 맞추는 것(정보 동기화), **얼라인**은 나아갈 방향·우선순위에 합의하는 것(방향 정렬). 싱크는 *사실*을, 얼라인은 *결정*을 맞춘다.

**부연**:
- "싱크 좀 맞출까요" = 30분 통화로 상황 공유. "얼라인이 안 됐다" = 각자 다른 목표를 향해 일하고 있다 — **후자가 훨씬 비싼 문제**다.
- 싱크는 **비동기로도 된다**(문서·스레드). 굳이 회의로 모으면 N명의 [[공수]]가 그대로 나간다. 반면 얼라인은 이견 조율이라 대개 동기 대화가 빠르다.
- 자주 싱크해야 한다는 건 대개 경계 설계가 나쁘다는 신호 — 팀 간 결합도가 높다는 뜻([[사일로]]의 반대 증상).
