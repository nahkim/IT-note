# 리소스 (Resource)

**한 줄 뜻**: 일에 투입할 수 있는 **자원** — 회의실에서는 대개 **사람(인력)**을 뜻한다. "리소스가 없어서요" = 사람이 부족하다.

**부연**:
- 기술 문맥의 리소스(CPU·메모리·파일 핸들)와 **같은 단어, 다른 뜻**이라 문서에서는 헷갈린다. 사람을 가리킬 땐 *인력*이라 쓰는 편이 낫다.
- 사람을 리소스라 부르는 말버릇에는 함정이 있다 — **개발자는 서로 교체 가능한 부품이 아니다.** 도메인 지식과 코드 히스토리는 이전되지 않는다([[핸드오버]]가 필요한 이유).
- "리소스 50% 투입"은 실제로는 두 프로젝트를 오가는 **컨텍스트 스위칭 비용**을 숨긴다. 절반씩 두 곳에 넣으면 산출은 절반+절반이 아니라 그보다 적다.
