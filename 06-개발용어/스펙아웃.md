# 스펙아웃 (Spec out / Scope out)

**한 줄 뜻**: **두 가지 정반대 뜻으로 쓰이는 위험한 말** — ① 기능 사양을 상세히 **뽑아내다**(spec **out** = 명세화) ② 이번 범위에서 **빼다**(scope **out** = 제외).

**부연**:
- 그래서 "그 기능 스펙아웃 됐어요"는 **"명세 나왔다"로도, "이번엔 안 한다"로도** 들린다. 회의록에 쓸 땐 *"이번 스프린트 범위에서 제외"* 처럼 풀어 적는 게 사고를 막는다.
- 실무 빈도는 ②(제외) 쪽이 더 높다. 일정이 밀릴 때 나오는 첫 카드가 "스펙아웃하죠"다 — [[스콥 크립]]의 반대 방향 조정.
- ①의 뜻으로 쓸 때는 보통 요건 정의 → 화면 설계 → 예외 케이스 정리까지를 묶어 부른다. 여기서 [[경계 조건]]·[[엣지 케이스]]를 못 잡으면 개발 중에 다시 돌아온다.

**관련**: [[스콥 크립]] · [[백로그]] · [[엣지 케이스]] · [[킥오프]]
