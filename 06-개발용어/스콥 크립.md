# 스콥 크립 (Scope Creep)

**한 줄 뜻**: 일정과 [[공수]]는 그대로인데 **할 일만 슬금슬금 늘어나는 현상**. 한 번에 크게 늘지 않고 "이것만 더" 가 쌓여서 커진다는 게 이름의 핵심(*creep* = 기어들다).

**부연**:
- 전형적 경로: 명세가 애매함 → 개발 중 해석 차이 발견 → "겸사겸사 이것도" → 완료 기준 없음 → 무한 연장.
- 사촌 격인 **골드 플레이팅**은 아무도 요구하지 않은 것을 **개발자가 스스로** 얹는 것. 방향만 반대일 뿐 결과는 같다([[오버엔지니어링]]과 맞닿음).
- 막는 법은 거절이 아니라 **교환**이다: "넣을 수 있습니다. 대신 무엇을 [[스펙아웃]]할까요?" — 일정·범위·품질의 [[트레이드오프]]를 상대에게 보여주는 것.
- 예방은 착수 전에 **완료 기준(Definition of Done)** 과 *안 하는 것* 목록을 적어 두는 것. [[킥오프]]·[[백로그 그루밍]]의 실질적 목적이 이것이다.

**관련**: [[스펙아웃]] · [[백로그 그루밍]] · [[오버엔지니어링]] · [[트레이드오프]] · [[공수]]
