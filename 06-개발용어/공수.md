# 공수 (工數, Man-day / Man-month)

**한 줄 뜻**: 어떤 일을 끝내는 데 드는 **사람 × 시간**의 양. "이 기능 공수 얼마 나와요?"는 **며칠짜리 일이냐**는 뜻이다. 단위는 **인일(man-day)·인월(man-month)**.

**부연**:
- 일본 제조업 용어 **工数(こうすう)** 가 그대로 넘어온 말. 그래서 사전보다 회의실에서 먼저 배운다.
- **공수 ≠ 기간**. 6인월짜리 일을 6명이 붙인다고 1개월에 끝나지 않는다 — 커뮤니케이션 비용이 사람 수의 제곱으로 는다(*맨먼스 미신*, 브룩스). "늦은 프로젝트에 사람을 더 넣으면 더 늦어진다."
- 산정할 때 빠뜨리는 것들: 코드 리뷰·QA 대응·배포·회의·[[플레이키 테스트]] 재실행. **개발 시간만 세면 항상 모자란다.**
- 그래서 실무에선 산정치에 **[[버퍼와 리드타임|버퍼]]**를 얹거나, 낙관/현실/비관 3점 추정을 쓴다.

**관련**: [[버퍼와 리드타임]] · [[스프린트]] · [[스콥 크립]] · [[기술부채]]

---
> 참고 — 국내 IT 현장에서 그대로 쓰이는 관용어(工数 유래). 브룩스의 맨먼스 미신은 『The Mythical Man-Month』(1975)의 논지.
