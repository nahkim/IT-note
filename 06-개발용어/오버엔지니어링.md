# 오버엔지니어링 (Over-engineering)

**한 줄 뜻**: 지금 필요하지도 않은 상황에 대비해 **필요 이상으로 복잡하게 만드는 것**. 추상화 계층, 설정 옵션, 확장 포인트가 쓰이지도 않은 채 유지비만 먹는다.

**부연**:
- 대개 선의에서 나온다 — "나중에 바뀔 테니 미리 유연하게". 문제는 **미래 예측이 대체로 틀린다**는 것. 엉뚱한 방향으로 유연해진 코드는 오히려 바꾸기 더 어렵다.
- 대응 원칙 둘: **YAGNI**(You Aren't Gonna Need It — 필요해질 때 만들어라), **KISS**(단순하게 유지하라).
- 반대편 실패도 있다는 걸 잊지 말 것 — **언더엔지니어링**(설계 없이 쌓기)은 곧장 [[기술부채]]가 된다. 요령은 "복잡성을 **지금 지불할 근거**가 있는가"를 묻는 것이고, 이건 결국 [[트레이드오프]] 판단이다.
- 판별 질문: 이 추상화는 지금 **구현체가 둘 이상**인가? 이 설정값을 **실제로 바꿀 사람**이 있는가? 아니면 대개 과잉이다.
- 요구되지 않은 완성도를 스스로 얹는 **골드 플레이팅**은 [[스콥 크립]]의 개발자 버전.
