# 핫픽스 (Hotfix)

**한 줄 뜻**: 정규 배포 일정을 **기다리지 않고 즉시 내보내는 긴급 수정**. 운영 중인 서비스가 이미 아프기 때문에 절차를 줄여서 나간다.

**부연**:
- 보통 **최소 변경 원칙** — 지금 터진 것만 고친다. 김에 리팩터링을 얹는 순간 검증 범위가 폭발한다.
- 흐름: 운영에 나가 있는 태그·릴리스 브랜치에서 분기 → 수정 → 배포 → **main에도 반드시 반영**(안 하면 다음 배포에서 같은 버그가 되살아나는 고전적 [[회귀]]). 이때 쓰는 게 [[체리픽]].
- 절차를 줄인 만큼 **사후가 중요하다** — 왜 정규 배포로 못 잡았는지는 [[포스트모템]]에서 다룬다. 핫픽스가 잦다면 그건 배포 주기나 테스트의 문제.
- 급할수록 **롤백 경로를 먼저** 확인한다. 되돌릴 수 없는 배포(마이그레이션 포함)는 핫픽스로 하기에 가장 위험한 종류.
