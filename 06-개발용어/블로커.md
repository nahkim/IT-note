# 블로커 (Blocker)

**한 줄 뜻**: 그것 때문에 **일이 아예 못 나아가는 것**. 느려지는 정도가 아니라 **멈춘** 상태.

**부연**:
- 대부분의 블로커는 기술이 아니라 **사람과 권한**이다 — [[컨펌]] 대기, 계정·권한 미발급, 다른 팀 API 미완성, 결정권자 부재.
- 그래서 블로커는 **말해야만 풀린다.** 혼자 붙들고 있으면 남들 눈엔 그냥 "진행 중"으로 보인다 → [[데일리 스탠드업]]과 [[이슈업]]이 존재하는 이유.
- 판단 기준: **"내 힘만으로 오늘 안에 풀 수 있나?"** 아니라면 블로커다.
- 개인 차원 대응은 병렬 작업으로 갈아타기지만, **팀 차원 대응은 블로커 자체를 없애는 것**이다. 같은 블로커가 반복되면 [[회고]] 안건.
